# Генератор персонажей — Дикоземье

Standalone HTML-генератор персонажей для «Дикоземья». Вся логика — в JS внутри
страницы, без бэкенда и внешних зависимостей. Открывается локально и без интернета.

Открыть: https://dexius9669.github.io/mt_chargen/

## Что внутри

- `character_generator_MT.html` — самодостаточный пошаговый генератор персонажа:
  вопросы, «Суть Героя», Таблица Вдохновения (d66 × 3), Культура (2d6), Аспекты,
  важные предметы и инвентарь, с сохранением и экспортом в Markdown.
- `index.html` — редирект на генератор для корня сайта.
